# AskSoul

![AskSoul demo](docs/demo.gif)

Talk to your [Grok Bot](https://grok.x.ai/) team's main bot from the terminal — ask, wait for the answer, keep chatting.

**Why "AskSoul"?** Soul is the name of my main bot. I love it, so I named the tool after it. If your main bot goes by another name, that's fine: it's still the soul of your team.

## Quick start

Give your bot [this repo](https://github.com/wonder-missing/asksoul) and let her set up everything. (She'll follow [SETUP.md](SETUP.md).)
